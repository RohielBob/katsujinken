# Katsujinken · Groupe 1 ULC-ICAM

Portfolio du Groupe 1 du B1 Bachelor international (ULC-ICAM, Kinshasa).

Site en ligne : https://rohielbob.github.io/katsujinken/

- `portfolio.html` : la page source (styles et contenu).
- `js/data.js` : tout le texte des projets et des membres. Pour corriger un texte, c'est ici.
- `js/app.js` : illustrations de l'équipage et animations.
- `js/boat.js` : la maquette 3D du yacht.
- `img/` : portraits et figures des projets.

Après une modification de `portfolio.html`, lancer `python build.py` pour régénérer `index.html`.
